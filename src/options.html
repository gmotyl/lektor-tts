Lektor TTS

Lektor reads web pages aloud through a text-to-speech server. Choose one to get started.

Speech engine

Must speak the OpenAI /audio/speech API. A server other than localhost asks for permission to reach it.

Install and start it with the Quick start (one command: ./omnivoicectl start). Needs an NVIDIA GPU for real-time speech.

Create one at platform.openai.com → API keys. Stored in your browser's sync storage, sent only to OpenAI.

More settings: speed, autoscroll, model

0.5 to 2.0.

Scroll the page to the sentence being read. Also on the player bar.
